# KhelConnect - Sports Department Portal

KhelConnect is a modern, responsive web application developed for the Sports Department of the Government of India. The portal serves as a comprehensive platform for promoting sporting events, showcasing athlete information, and providing up-to-date sports news.

## Features

- **Event Management**: View and explore upcoming sports events
- **Athlete Profiles**: Access detailed information about athletes
- **News Updates**: Stay informed with the latest sports news
- **Responsive Design**: Mobile-friendly interface
- **Interactive UI**: Modern and user-friendly experience

## Technologies Used

- HTML5 (Semantic Layout)
- CSS3 (Responsive Design)
- JavaScript (ECMA 2024)
  - Functional Programming
  - Object-Oriented Programming
- jQuery 3.7.x
- Bootstrap 5.x
